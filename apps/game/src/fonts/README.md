# Fuentes locales de la interfaz

Estas tipografías de Google Fonts se distribuyen sin modificar, con su licencia SIL Open Font License 1.1 junto a cada archivo:

- [IM Fell English](https://github.com/google/fonts/tree/main/ofl/imfellenglish), Igino Marini.
- [Cinzel](https://github.com/google/fonts/tree/main/ofl/cinzel).
- [Alegreya](https://github.com/google/fonts/tree/main/ofl/alegreya).
- [Cormorant Garamond](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond).

Los archivos variables se guardan como `Roman.ttf` conservando sus bytes originales. Georgia utiliza la fuente del sistema. El selector guarda su elección localmente. No se modifican las imágenes ni las letras dibujadas en los sprites del HUD original.
