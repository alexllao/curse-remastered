# IM Fell English

Tipografía de Igino Marini para la interfaz propia del port y la pantalla de carga. No modifica los sprites de texto del juego original.

Fuente sin modificar: [Google Fonts](https://github.com/google/fonts/tree/main/ofl/imfellenglish), archivo `IMFeENrm28P.ttf`. Se distribuye localmente con su licencia SIL Open Font License 1.1 en `OFL.txt`, para que la interfaz no dependa de servicios externos durante la ejecución.
